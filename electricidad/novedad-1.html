Llegó el nuevo Set de Parlantes Torre

Después de meses de pruebas, por fin sumamos a nuestro catálogo el nuevo Set de Parlantes Torre: dos torres activas con graves profundos, conexión Bluetooth estable y entradas auxiliares para micrófono e instrumentos.
